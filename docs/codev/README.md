# CoDev

You never have to name a skill. Describe what you want, and CoDev resolves it to one of
four steps — **Understand, Build, Review, Ship** — plus two that only show up when the
work actually needs them: **Specify** for a genuinely new product, **Launch** for a real
rollout decision. The AI supplies evidence; you supply authority.

Full documentation — the onboarding guide, four narrated tutorials, the command
checklist, copy-paste starting prompts, and worked examples — lives on the website:
**https://urban233.github.io/CoDev/**

A skill-card template for writing your own skill's `skill-card.md` is at
`docs/codev/onboarding/skill-card.template.md`, alongside this file.
