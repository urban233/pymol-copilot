### Two-direction fix demonstration (H02-S3-F3, H02-S3-F10)

Per this slice's own standard (restated from slice 3's review: "a guard that
cannot fail is worse than no guard"), both fixes were demonstrated in both
directions: reverted under a trap that restores the file byte-for-byte
(verified with a SHA-256 checksum), observed to fail, restored, and re-run
clean.

Fixed-file checksum (`tests/discovery/h02/execution_boundary.py`, both fixes
in place):
`7b2ae72d0a9e239da3d352b04217e6521c038bdb307830427fc4efb00cd1ac44`.

**H02-S3-F3:** `_terminate_and_reap`'s body was temporarily replaced with a
single `return` (a no-op), leaving the rest of the file, including the
surrounding `try`/`finally` structure, untouched. Running
`bazel test //tests/discovery/h02:execution_boundary_probes
--nocache_test_results --test_output=errors` against the reverted file
produced **1 failed, 16 passed**: only the new
`test_child_that_escapes_before_communicate_is_terminated_and_reaped` failed,
with `AssertionError: child process was not reaped` (`assert None is not
None`, from `poll()` returning `None`) -- the child spawned before the
injected exception was left running. The file was then restored from the
pre-revert copy; `sha256sum` matched
`7b2ae72d0a9e239da3d352b04217e6521c038bdb307830427fc4efb00cd1ac44` exactly,
and the same target re-ran **17 passed**, `--nocache_test_results`.

**H02-S3-F10:** every `child_pid=child_pid`/
`child_terminated=process.poll() is not None` pair in `execute()`'s three
return sites was temporarily replaced with `child_pid=None`/
`child_terminated=None`, leaving the dataclass fields, the schema-version
bump, and `_terminate_and_reap` itself untouched. Running the same target
against the reverted file produced **4 failed, 13 passed**:
`test_spawn_or_load_failure_fails_closed_with_no_leak`
(`assert None == 18`), `test_wall_clock_timeout_is_hard_killed_and_reaped`
(`assert None == 20`),
`test_forced_child_crash_leaves_no_live_process_or_scratch_data`
(`assert None == 22`), and
`test_positive_path_matches_independently_computed_expected_values`
(`assert None == 34`) -- each asserting `report.child_pid ==
spawned[N].pid` against a report that no longer carried it. The file was
restored from the pre-revert copy; `sha256sum` again matched
`7b2ae72d0a9e239da3d352b04217e6521c038bdb307830427fc4efb00cd1ac44`
exactly (confirmed both by checksum and a byte-for-byte `diff`), and the
same target re-ran **17 passed**, `--nocache_test_results`.

The rejected-path tests (which assert `child_pid is None`/
`child_terminated is None`) pass under both the fixed and the F10-reverted
file, as expected: a rejected request never spawns a process either way, so
that assertion cannot discriminate the fix -- it is the four spawned-process
tests above that give the fix its teeth.
