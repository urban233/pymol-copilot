# Discovery tests

Owned by full-V1 contract discovery (H-02, M-02; part of the
[full-V1 contract wave](../../docs/codev/wave/pymol-copilot-full-v1-contracts.md)).
Retains only the probes, fixtures, and machine-readable results that are
useful acceptance evidence for the candidate serialization, reconstruction,
and execution-boundary comparison this wave's fixture-freeze and
contract-freeze checkpoints depend on. Nothing under this directory is a
production snapshot, card, or executor API -- that ships only after the
contract-freeze checkpoint accepts one candidate.
